🏫 先生の画面

生徒の 練習が 見える・ログインカードを 印刷する。先生だけが 使う画面です。生徒や 保護者は ここを 使いません。

はじめての先生（アカウントを 作る）

① ご自分の お名前か、教室の 名前を 入れます。あとから 変えられます。

② いつも 使っている メールアドレスを 入れます。パスワードを 忘れたときの 連絡に 使います。生徒や 保護者には 見えません。

③ パスワードを ご自分で 決めて 入れます（8文字以上）。どこかから 送られてくるものでは ありません。
右の 「見る」を 押すと 入れた文字が 見えます。紙に 控えておくと 安心です。

④ 3つとも 入れたら、下の 黒いボタンを 押します。

2回目からは：ログインする（アカウントを 持っている）

パスワードを 忘れた（メールで 作りなおす）

生徒側は ログイン不要です。先生が 登録した にっくねーむを 選ぶだけで 使えます。メール・本名・生年月日は 集めません。

教室

教室の 名前を 入れて 「＋ 教室を 作る」を 押します。曜日や 学年で 分けても かまいません。あとから いくつでも 作れます。

← 教室の一覧

クラスコード

これが この教室の 合いことばです。子どもは アプリの「🏫 教室に 参加」で この6文字を 入れ、自分の名前を えらぶだけ。パスワードは ありません。
この6文字は 下の ログインカードにも 入ります。

生徒

下の 欄に 生徒の 名前を 1行に 1人ずつ（改行して ください）。本名で なくて かまいません。子どもが 自分で 見つけられる 呼び名に します。

書き終わったら 下の 黒いボタンを 押すと 登録されます。あとから いつでも 足せます。
