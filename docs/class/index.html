🏫 先生の画面

生徒の 練習が 見える・ログインカードを 印刷する。先生だけが 使う画面です。生徒や 保護者は ここを 使いません。

はじめての先生（アカウントを 作る）

① ご自分の お名前か、教室の 名前を 入れます。あとから 変えられます。

② いつも 使っている メールアドレスを 入れます。パスワードを 忘れたときの 連絡に 使います。生徒や 保護者には 見えません。

③ パスワードを ご自分で 決めて 入れます（8文字以上）。どこかから 送られてくるものでは ありません。
右の 「見る」を 押すと 入れた文字が 見えます。紙に 控えておくと 安心です。

④ 3つとも 入れたら、下の 黒いボタンを 押します。

2回目からは：ログインする（アカウントを 持っている）

パスワードを 忘れた（メールで 作りなおす）

生徒側は ログイン不要です。先生が 登録した にっくねーむを 選ぶだけで 使えます。メール・本名・生年月日は 集めません。

教室

教室の 名前を 押すと、その教室の 画面に なります。

教室の 名前を 入れる

教室の 名前を 入れて、下の 黒いボタンを 押します。曜日や 学年で 分けても かまいません。あとから いくつでも 作れます。

　生徒の 名前を 入れる

下の 白い欄に、生徒の 名前を 書きます。2人以上のときは 1行に 1人ずつ（改行して ください）。本名で なくて かまいません。子どもが 自分で 見つけられる 呼び名に します。

ログインカードを 印刷する

下に 1人 1枚の カードが 見えています。黒いボタンを 押すと 印刷の 窓が 出るので、そこで「印刷」を 押してください。
紙が なくても、カードに 書いてある 6文字と 名前を 子どもに 伝えれば 同じです。

「保護者への 案内」は A4 1枚の お知らせ（使い方・ご家庭の お金は かからない・個人情報は 集めない）。カードと いっしょに 渡すだけで OK です。

✓ 印刷できました。カードを 子どもに 渡してください。子どもが 家で 練習すると、教室の 画面に 自動で 出ます。

この教室の 合いことば：
カードに 印刷されています。子どもは アプリの「🏫 教室に 参加」で これを 入れて、自分の 名前を えらびます。パスワードは ありません。

📨 宿題を 出す

しゅもく・級・何セットを えらんで 「📨 宿題を 出す」を 押します。子どもの ホーム画面に「先生からの 宿題」として 出て、やった ぶんは 上の 表に 自動で 入ります。

⚙️ くわしい 設定（級の 基準・教室を 消す）

「級の基準」＝ この教室で 使う 級の 表（何級が 何桁 何口か）。標準は 20級（入門）〜十段、標準（10級から）は 入門の級を 使いません。ふつうは 変えなくて だいじょうぶです。

📊 級体系の くらべ表（どの級が だいたい 同じか・めやす）

教室を 消すと、生徒と 記録も ぜんぶ 消えます。もとに もどせません。
