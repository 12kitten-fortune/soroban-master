アバター

① 各部と「入れる・払う」

枠・梁・桁・定位点・一玉(=1)・五玉(=5)。中央の赤い点＝一の位（小数点）。梁に寄せる＝入れる／離す＝払う。始めは「ご破算」で0に。

② 指づかい
  • 一玉を上げる＝親指／下げる＝人差し指／五玉＝人差し指
  • 6〜9は五玉＋一玉を同時に（このアプリは数字キーで同時操作可）。
③ 5の友

1↔4 / 2↔3。たし算：五玉を入れて5の友を払う（4＋1＝五玉入れて4払う）。ひき算は逆。

④ 10の友（繰り上がり・繰り下がり）

1↔9 / 2↔8 / 3↔7 / 4↔6 / 5↔5。繰り上がり：隣に1、10の友を払う（7＋6→13）。繰り下がりは逆（13−6→7）。

⑤ 掛け算

両置き→片落とし→両落とし。先に定位点で一の位を決めると答えをそのまま読める。九九1桁は「が」＝0に注意。

⑥ 検定基準（級）

珠算＝各種目15問・7分・150点満点中100点以上。暗算＝20問・3分・100点満点中70点以上。フラッシュ＝20問・200点満点中140点以上。（段位の難易度は自動目安）
