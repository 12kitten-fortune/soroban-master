# 言葉のファイル（多言語の 土台）

- `catalog.ja.json` … 画面に 出る 日本語の 一覧（自動で 作る。手で 直さない）。
  作り直し：リポジトリの いちばん上で `node tools_言葉の一覧を作る.mjs`
- `en.js` など … 訳の 辞書。まだ 無い（作るときは 下の 形）。

## しくみ

- プログラムの 中の 日本語は `T("…")` を 通っている（`docs/i18n.js`）。
  いまの 言語の 辞書に その日本語が あれば 訳を 返し、無ければ 日本語の まま。
- `{名前}` は あとから 数字などが 入る 場所。訳の 中でも 同じ `{名前}` を そのまま 使う。
  例：`"あと{n}問"` → `"{n} more"`
- HTML に 直接 書いてある 文字（メニュー・説明）は、言語を 切りかえたとき `translateDOM()` が 辞書で 置きかえる。
- 級の 名前（20級・初段 など）は データなので 訳さない。しゅもくの 名前・級体系の 名前は 訳す。

## 英語を 足す 手順

1. `catalog.ja.json` を 写して `en.js` を 作る
2. 中身を この形に する（訳さない 行は 消してよい。無い 言葉は 日本語の まま 出る）

```js
window.SK_LANG_DICT = {
  "▶ スタート": "▶ Start",
  "あと{n}問": "{n} more",
  "🏠 ホーム": "🏠 Home",
};
```

3. 切りかえ：`SK_I18N.setLang("en")`（設定画面に 言語の えらび方を 足すのは 英語版を 作るとき）

## 注意

- `catalog.ja.json` には 文の 一部だけの 項目（「（」「年」など、文字を つないで 作っている 所）も 混ざっている。
  英語に するときは、そのような 所は プログラム側を 1つの 文に 直してから 訳す。
- 数字の 単位（問・分・秒・級）の 語順は 言語で 変わるので、`{n}問` の ような 項目は 訳で 語順を 入れかえる。
