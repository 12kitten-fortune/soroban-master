▶ 練習をはじめる（むりょう）

お申し込み ありがとうございます

お申し込みを 受けつけました。先生画面への プランの 反映は 1〜2営業日 以内に 行い、メールで お知らせします。初月（31日間）は 無料です。

つぎに すること

  1. 先生画面（sorobankingdom.com/class/）を、お申し込みと 同じ メールアドレスで 作ってあるか 確かめる（まだなら 作ってください）
  2. 反映の お知らせが 届いたら、先生画面を 開きなおす → 上の 青い帯が「教室プラン」などに 変わります
  3. 生徒を 登録し、「ログインカード」と「保護者への 案内」を 印刷して 渡す

家庭プランの 方は

  1. 保護者の方が 先生画面（sorobankingdom.com/class/）を、お申し込みと 同じ メールアドレスで 作る（「はじめての先生」から。お名前は 保護者の お名前で かまいません）
  2. 反映の お知らせが 届いたら 開きなおす → 上の帯が「家庭プラン」に 変わります
  3. 「教室を 作る」で おうちの 名前（例：すとう家）→ お子さまの にっくねーむを 登録 → 出てきた クラスコードを お子さまの 端末の「🏫 教室に 参加」に 入れる
  4. これで お子さまの 記録が 保護者の 画面に 届きます。くわしくは ご家庭の方へ
