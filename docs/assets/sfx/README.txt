ここに mp3 を置くと、アプリが その音を鳴らします（置かなければ 今までどおり合成音）。

ファイル名（すべて mp3）
  correct.mp3   … 正解のとき（ピンポン）
  wrong.mp3     … まちがえたとき
  clear.mp3     … 1セット終わり・パズルクリアの小さいファンファーレ
  levelup.mp3   … 検定合格・レベルアップの大きいファンファーレ
  coin.mp3      … GOLDをもらったとき
  pop.mp3       … パズルの玉が消えるとき
  rocket.mp3    … ロケット・TNTが発動したとき
  star.mp3      … ★がとんでくるとき
  click.mp3     … 珠を弾く・ボタンを押す
  bgm_study.mp3 … 練習中のBGM（ループ・静かめ）
  bgm_puzzle.mp3… パズル中のBGM（ループ）

無料でつかえる音源（商用可）
  効果音ラボ      https://soundeffect-lab.info/     クレジット表記なしでOK・日本語
  魔王魂          https://maou.audio/               BGM/効果音とも豊富
  DOVA-SYNDROME   https://dova-s.jp/                BGM中心（曲ごとに規約を確認）
  Pixabay         https://pixabay.com/sound-effects/ 表記不要
  Kenney          https://kenney.nl/assets?q=audio   CC0（完全に自由）

置いたら Ctrl+Shift+R で読みこみ直してください。
