========================================================
 素材の置き方（Kenney などの無料素材を つかうとき）
========================================================
Kenney（https://kenney.nl/assets）は すべて CC0 です。
・商用OK ・クレジット表記 不要 ・改変OK ・ライセンス文の同梱も不要
ZIPを落として、中の PNG / OGG を ここに置いてください。

--------------------------------------------------------
【1】音（いちばん効果が大きい）  → assets/sfx/ に置く
--------------------------------------------------------
mp3 / ogg / wav の どれでもOK（Kenneyは ogg が多い）。
ファイル名を こう変えるだけで 鳴るようになります。

  correct   … 正解     （Interface Sounds の confirmation_001 など）
  wrong     … 不正解   （error_004 / back_001 など）
  clear     … セット終わり・パズルクリア（jingles の positive）
  levelup   … 検定合格・レベルアップ（jingles の achievement）
  coin      … GOLD獲得 （Casino Audio / Coin Sounds）
  pop       … 玉が消える（Impact Sounds の impactGlass_light）
  rocket    … ロケット・TNT（Impact Sounds の impactBell / explosion）
  star      … ★がとぶ  （Interface Sounds の bong / tick）
  click     … 珠を弾く・ボタン（Interface Sounds の click_001）
  bgm_study … 練習中のBGM（ループ・静かめ）
  bgm_puzzle… パズル中のBGM（ループ）

おすすめパック（Kenney）
  Interface Sounds … ボタン・確定・エラー音が100種類ほど
  Impact Sounds    … ぶつかる・割れる音（玉が消える音に）
  Casino Audio     … コイン・チップの音（GOLDに）
  Music Jingles    … 短いファンファーレ（クリア・合格に）
  ※BGMは Kenney には少ないので、魔王魂 や DOVA-SYNDROME の方が向きます

--------------------------------------------------------
【2】つぶ・きらめき  → assets/fx/ に置く
--------------------------------------------------------
  Particle Pack の star_01.png / spark_01.png / smoke_01.png など
  いまは CSSの丸で代用しているので、これを置くと 花火が本物になります

--------------------------------------------------------
【3】枠・ボタン  → assets/ui/ に置く
--------------------------------------------------------
  UI Pack / UI Pack RPG Expansion
  金色の枠・パネル・丸ボタンが そろっています
  （いまは CSSで それらしく描いています）

--------------------------------------------------------
【4】アイコン  → assets/ui/ に置く
--------------------------------------------------------
  Game Icons … ★ 歯車 トロフィー 音量 など
  Board Game Icons / Playing Cards Pack … トランプの絵柄

--------------------------------------------------------
【注意】
・Kenney のフォントは 英数字だけです。日本語は表示できないので、
  文字は いまのまま（端末のフォント）を使います。
・置いたら Ctrl+Shift+R で読みこみ直してください。
・ファイル名が わからない・多すぎる ときは、ZIPを解いたフォルダごと
  どこかに置いて「このフォルダを見て」と言ってもらえれば、
  こちらで 中身を確認して 選び・名前をつけ・組みこみます。
