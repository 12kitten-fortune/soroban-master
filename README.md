# 🧮 そろばん道場（Soroban Master）

日本の本格そろばん・暗算を、ゲーム感覚で学べる Web アプリ。
**計算は答えが確定するので採点は完全自動**。APIキー不要・ネット接続不要で動きます。

## 機能
- **級・段を選ぶ**：20級〜十段のラダーから選択（全珠連準拠。段位と11〜20級は自動目安）
- **種目**：みとり算／かけ算／わり算／あんざん／フラッシュ暗算
- **そろばん解答**：画面のそろばんを**指ドラッグ or 数字キー**で操作（五玉＋一玉が同時に動く／「パチ」音／中央の赤い点＝一の位）
- **こたえ合わせ**：赤い◎／×表示、正解「ピンポン♪」・不正解「ブブー」音
- **採点方式**：1問ずつ採点 ／ 全問回答後にまとめて採点（検定方式）
- **タイマー**：制限時間（検定形式）ON/OFF、タイムを計測
- **記録・認定**：自己ベストタイム、連続学習、合格で級・段を認定、今月のがんばり

## 構成
- `docs/` … 公開する静的サイト本体（HTML/CSS/JS。GitHub Pages はここを配信）
- `server.js` … ローカル確認用の簡易サーバー（Express、`docs/` を配信）

## ローカルで動かす
```bash
npm install
npm start          # → http://localhost:3200
```
`docs/index.html` をブラウザで直接開いても動きます（サーバー不要）。

## ネット公開（GitHub Pages）
このリポジトリの **main ブランチ / docs フォルダ** を GitHub Pages のソースに設定すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で世界中に公開できます。
